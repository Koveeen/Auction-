# Auction Digest

Программный сервис для мониторинга нумизматических аукционов. n8n не требуется.

## Поток

1. Планировщик запускает `python -m auction_digest.cli` ежедневно.
2. Сервис запускает настроенный Apify Actor для каждого источника.
3. Лоты приводятся к единому формату, фильтруются по `config.yaml` и сохраняются в SQLite.
4. Раз в неделю новые подходящие лоты отправляются в Telegram.

Первый адаптер — Heritage. Остальные аукционные дома подключаются отдельными адаптерами, без изменения правил фильтрации.

## Переменные окружения

```text
APIFY_TOKEN=...
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Токены добавляются в Railway Variables, в чат их передавать не нужно.

## Локальная проверка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m auction_digest.cli --dry-run
```

## Railway

Создать сервис из репозитория, команда запуска:

```bash
python -m auction_digest.cli
```

Расписание Cron Job: `0 6 * * *` (06:00 UTC; при необходимости меняется под часовой пояс). Еженедельный дайджест по умолчанию отправляется по понедельникам.
